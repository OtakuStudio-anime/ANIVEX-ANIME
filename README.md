# ANIVEX — APKs oficiales

Este repositorio público distribuye las versiones instalables de ANIVEX para Android.

## Descargar
Abre [Releases](https://github.com/OtakuStudio-anime/ANIVEX-ANIME/releases) y descarga el APK adjunto a la versión que quieras instalar.

## Estado
Todavía no hay una APK publicada. La primera versión se publicará después de que el proyecto compile y pasen las pruebas automatizadas.

Las primeras entregas serán builds de prueba (debug), no firmadas para producción. No instales APKs de fuentes no oficiales.

Código fuente privado: https://github.com/OtakuStudio-anime/ANIVEX
